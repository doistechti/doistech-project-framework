# FEATURE.md

## ID

`FEAT-COM-0003`

## Objetivo

Permitir compartilhamento do evento publicado em canais externos.

## Estado

`canceled`

## Justificativa

Cancelada nesta linha de base por ausência de critérios comunitários estáveis e risco de ampliação de escopo.

## Critérios de aceite

- AC-COM-0007: canais externos precisam ser explicitamente aprovados;
- AC-COM-0008: eventos cancelados não podem ser compartilhados;
- AC-COM-0009: mudança de escopo exige registro formal.
