# Context Readiness Report

## Finalidade

Declarar se o contexto de uma execução é suficiente para início seguro.

## Campos obrigatórios

- `report_id`
- `agent_profile`
- `project_id`
- `capability_id`
- `epic_id`
- `feature_id`
- `task_id`
- `documents_checked`
- `business_rules_checked`
- `adrs_checked`
- `dependencies_checked`
- `risks_checked`
- `dor_status`
- `gaps_found`
- `ready_to_start`
