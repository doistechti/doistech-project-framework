# Agent Handoff Contract

## Finalidade

Transferir trabalho entre agentes sem depender do histórico completo da conversa.

## Campos obrigatórios

- `handoff_id`
- `from_agent`
- `to_agent`
- `objective`
- `current_state`
- `context_summary`
- `relevant_artifacts`
- `decisions_in_force`
- `work_completed`
- `work_pending`
- `risks`
- `blockers`
- `evidence_refs`
- `open_questions`
- `expected_action`
- `completion_condition`
