# DoisTech TI — engenharia de software e soluções digitais

> **Desenvolvimento de sistemas, APIs, plataformas SaaS e soluções com inteligência artificial.**

A **DoisTech TI** desenvolve software sob medida e soluções digitais para empresas. Nosso trabalho combina entendimento de regras de negócio, arquitetura de software e integração de sistemas para transformar demandas operacionais em produtos sustentáveis.

## O que fazemos

- **Sistemas e plataformas SaaS:** aplicações web, gestão de processos e soluções multi-tenant.
- **Backends e APIs:** Java, Spring Boot, APIs REST, autenticação e integrações entre sistemas.
- **Aplicações frontend:** interfaces web com React e TypeScript.
- **Integrações e automação:** serviços empresariais, marketplaces, webhooks e fluxos automatizados.
- **IA aplicada:** integração com LLMs, agentes supervisionados, gestão de uso e custos de modelos.

## Tecnologias e práticas

| Área | Stack e práticas |
| --- | --- |
| Backend | Java 21, Spring Boot, Spring Security, JWT, JPA/Hibernate, Flyway |
| Frontend | React, TypeScript, Vite, React Query |
| Dados | PostgreSQL, MySQL, MariaDB |
| Qualidade | JUnit 5, Testcontainers, testes de integração |
| Infraestrutura | Docker, Linux, EasyPanel, armazenamento compatível com S3 |
| Arquitetura | APIs REST, microsserviços, SaaS, multi-tenancy, modelagem de regras de negócio |
| IA | APIs de LLMs, RAG, roteamento entre provedores, automação e agentes |

## Projetos abertos em destaque

### [DoisTech Project Framework (DPF)](https://github.com/doistechti/doistech-project-framework)

Framework de engenharia de software *documentation-first* para projetos desenvolvidos por pessoas e agentes de IA. Organiza especificações, contexto, capacidades, funcionalidades e tarefas com rastreabilidade e validação.

### [DoisTech IA Service](https://github.com/doistechti/doistecht-ia-service)

Gateway de IA em Java que oferece uma API unificada para diferentes projetos, com controle por cliente, monitoramento de consumo, estimativa de custos, RAG, resiliência e suporte a múltiplos provedores.

### [Pedido API — Spring, Camel e Batch](https://github.com/doistechti/pedido-api-spring-camel-batch)

Projeto de API em Java com Spring, Apache Camel e Spring Batch para demonstrar processamento e integração.

### [API RESTful Task](https://github.com/doistechti/api-restful-task)

Projeto público de API REST para demonstrar desenvolvimento backend.
